## 0. 结论速览

1. **两组产物同源且可逐字节证明**：明文运行环境包 13 文件 / 613,012,944 B；NarutoWorld 内同名目录 16 文件 / 613,020,768 B。13 个同名文件中 **12 个 SHA-256 完全一致**，唯一差异是 `使用说明.md`（1717→1738 B，末尾加一行「火影开源复刻组」）；B 侧另多 2 份倡议书与 1 个 `.bak`。

### 4.3 GM 面路由与安全设计（gm-server.jar 常量池 + javap 注解解析）

| 类级前缀 | 方法级映射（HTTP 方法 路径） | 角色要求 |
|---|---|---|
| `/auth` | POST `/login`、POST `/refreshToken`、GET `/getUserInfo`、POST `/logout` | 无（前两者免鉴权） |
| `/players` | GET `""`、GET `/accounts`、GET `/accounts/{accountId}`、GET `/{characterId}`、PATCH `/{characterId}`、PATCH `/accounts/{accountId}/status`、POST `/grant`、GET `/grant/items`、POST `/grant/batch` | 写操作 SUPER_ADMIN/OPERATOR；改账号状态仅 SUPER_ADMIN |
| `/shop` | GET `/items`、GET `/summary`、POST `/items`、PUT `/items/{id}`、PATCH `/items/{id}/shelf`、POST `/reload` | 写 OPERATOR；`/reload` 仅 SUPER_ADMIN |
| `/catalog` | GET `/resources`、GET `/{resource}`、GET `/{resource}/hierarchy`、PUT `/{resource}/{id}` | 写 SUPER_ADMIN/OPERATOR |
| `/repair-mappings` | GET `/summary`、GET `""`、GET `/{id}`、PUT `/{id}`、POST `/{id}/evidence`、GET `/assets`、POST `/assets`、POST `/assets/import`、POST `/todo/sync` | 写 SUPER_ADMIN/OPERATOR |
| `/audit` | GET `""` | SUPER_ADMIN/AUDITOR（`SaMode.OR`） |
| `/dashboard` | GET `/summary` | 登录即可 |

- **鉴权**：sa-token，头 `Authorization: Bearer <token>`，`timeout 900` 秒、`is-concurrent false`、`is-share false`、`max-login-count 1`、token 随机 64 位；白名单仅 `/auth/login`、`/auth/refreshToken`、`/error`、`/actuator/health`。
- **口令**：`PasswordHasher` 用 BouncyCastle Argon2id，常量 `MEMORY_KB=16384 / ITERATIONS=2 / PARALLELISM=1 / VERSION=19`，编码格式 `$argon2id$v=19$m=%d,t=%d,p=%d$salt$hash`。
- **登录防护**：`UPDATE gm_users SET failed_login_count=failed_login_count+1, locked_until=IF(failed_login_count+1>=5, DATE_ADD(NOW(6), INTERVAL 15 MINUTE), locked_until)`；Caffeine 本地限流；成功后清零并写 `last_login_at`。
- **Refresh token**：库内只存 `SHA-256` 摘要（`token_hash`），轮换用 `revoked_at` + `replaced_by_hash`，默认 7 天（`gm.security.refresh-token-days`）。
- **幂等键**：高风险操作要求 `Idempotency-Key` 请求头，`request_hash = SHA-256(body)`，`INSERT IGNORE gm_idempotency_keys(...)` 冲突即报 `IDEMPOTENCY_CONFLICT`，结果缓存 `response_json` 24 小时；实现见 `GrantService` 的 `ITEM_GRANT` / `ITEM_GRANT_BATCH`。
- **审计**：`RequestIdFilter` 生成/透传 `X-Request-Id`，`gm_audit_logs` 记录 `before_json/after_json/ip/user_agent/success/error_message`（库内 7 行）。
- **角色权限**：`SUPER_ADMIN / OPERATOR / AUDITOR` → 权限串 `player:read|write、grant:create、shop:write、catalog:read|write、audit:read、dashboard:read、admin:write、server:operate`。
- **初始管理员**：`AdminBootstrap` 在 `gm_users` 为空时按 `GM_BOOTSTRAP_USERNAME/PASSWORD` 建号；口令短于 8 字符则拒绝创建并告警。
