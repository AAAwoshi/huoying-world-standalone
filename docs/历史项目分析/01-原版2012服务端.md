## 0. 结论速览

1. **rar 是原始一键端，zip 是同内容的广告站二次打包**：两包 `server\`（12 文件）与 `files.rz.linekong.com\`（1464 文件）**逐字节一致**（SHA-256 全等，0 差异）；rar 独有 `DB\` 三库备份（78,069,099 + 763,604 + 2,585,937 B），zip 独有 5 个广告文件（`配置文件.ini` 522 B + 3 个 `.url` + 被广告包裹的 `说明.txt` 1324 B）。**收录优先 rar**。
2. **两个自研 Java 进程可由 jar 内 .svn 泄漏源码完整还原**：`dataServer.jar`（2,409,341 B，主类 `com.pst.server.DBServer`，端口 28522）与 `game.jar`（3,252,999 B，主类 `com.pst.core.line.LineServerEngine`，端口 28523）；共泄漏 **19 + 44 = 63 份 .java 源文件**。
3. **主通道是自研 F002 二进制协议，不是 AMF**：协议头 `0xF0 0x02`、1 字节十进制数位和长度校验、2 字节长度，载荷为 `权令(2u)+用户ID(4u)+动作类型(2u)+内容`；数据落库动作类型固定 `3000`（`ClientCommand.datatransmit`）。AMF3 仅用于玩家上线与线信息两处。
4. **MySQL 实测：`game` 库 187 张表（184 MyISAM + 3 MEMORY，全部 utf8）+ 9 个触发器；`game_proxy` 库 9 张表、1035 个 MD5 无盐口令账号、5000 个激活码；`game_statistics` 库 12 张表**（唯一有数据的是 `log_quest`，25,234 行，2012-03-22 至 2012-09-11）。口令 1035/1035 全为 32 位十六进制 MD5，182 个可被 41 词弱口令表命中。
5. **平台不完整：config_lines 指向的 4 条分线战斗逻辑服（192.168.100.10:20200–20203）不在包内**。`config_lines` 的 `ip` 整数 `3232261130` = `0xC0A8640A` = 192.168.100.10；全包可执行 jar 仅 2 个，`game.jar` 内 `com/pst` 只有 44 个类，**无任何战斗/地图/AI 类**。
6. **前端是 2012-08-30 官方网页客户端抓包镜像**：`game.htm` 内嵌 `Main.swf`，默认 `server:'115.182.54.198'`、`port:'11500'`，`baseUrl` 指向 `http://files.rz.linekong.com/act_web_tiyan/`；1464 个文件中 **1405 个 SWF**。
7. **混入大量与游戏无关的浏览器缓存杂物**：IE 错误页模板、迅雷看片插件 Lua 配置（`kankan.xunlei.com`）、竞价广告 `bidconfig_v1.2.dat`（按 IE 历史记录投放）、`Thumbs.db`、`favcenter.db`、`down.db`（详见 `4.5）。
8. **安全与隐私风险高**：`proxool.properties` 明文 `root/123456`；`game_proxy.users` 1035 条真实账号 + MD5 无盐口令；`game.sql` 含 1031 个真实角色与 1018 条 `game_user` 记录（注册自 2012-03-22 起）；`game_admin` 为 MD5 管理口令。公开收录前必须删除 `DB\` 或脱敏。

## 4. 核心实现（源码级证据）

> 源码取自 jar 内 `*.svn/text-base/*.java.svn-base`（Subversion 原始副本），是**编译前原文**。编码混合：部分 UTF-8、部分 GBK（`ProtocolF002.java`、`Command.java` 为 GBK）。

### 4.1 dataServer.jar（19 个 `com/pst` 类 + 19 份 .java 泄漏）

| 类 | 作用（源码关键行） |
|---|---|
| `com.pst.server.DBServer` | 入口：读 log4j → `new InitSystem().action()` → `new Console().console()`；带 `stop` 参数走 `SystemConfig.systemStop()` |
| `com.pst.core.InitSystem` | 写 PID → 初始化 Proxool → 读 `data-config.xml` → 启动 MINA 监听 |
| `com.pst.core.comm.DataLitener` | `NioSocketAcceptor(availableProcessors()+1)`；收发缓冲 2048；`setWriteTimeout(10)` |

### 4.3 F002 自定义协议（`ProtocolF002.java`，15,131 B）

```
跨进程包格式：{协议头 0xF0 0x02}(2u) {长度校验位}(1u) {包长度}(2u) {载荷}
载荷 parseCmdBytes()：{权令 pt}(2u) {用户ID}(4u) {动作类型 action}(2u) {内容}(Nu)；长度 < 8 直接丢弃
打包 packToServerProtocolBytes()：同上，权令/用户ID 由调用方给出，实际大量写作 (data, cmd, 1, 1)
长度校验 getProtocolPackLenVertify()：Σ(每个长度字节的无符号十进制表示的各数位)
```

- 协议头常量 `PROTOCALHEAD = new byte[]{-16, 2}`（0xF0 0x02）。
- 版本注释 `090702:把用户ID(5u)拆分成 特殊数值位(1u)+把用户ID(5u)` 与实现不符（当前为 `2+4+2=8`），**以代码为准**。
- Flash 策略文件：`F002ProtocolDecoder.doDecode` 识别 `policy-file-request` 后回写 `cross-domain-policy`（`allow-access-from domain="*" to-ports="*"`）并关闭连接。
- 动作类型 `3000` = 数据传送（SQL 文本，UTF-8）。

**片段 A — 两包逐字节比对**

```python
import os, hashlib
A = r'C:/Project/hy_analysis/x/服务端rar/火影世界服务端'
B = r'C:/Project/hy_analysis/x/服务端zip/火影世界服务端'
def walk(root):
    d = {}
    for dp, dn, fns in os.walk(root):
        for fn in fns:
            fp = os.path.join(dp, fn)
            d[os.path.relpath(fp, root)] = fp
    return d
def sha(fp):
    return hashlib.file_digest(open(fp, 'rb'), 'sha256').hexdigest()
for sub in ['server', 'files.rz.linekong.com']:
    da, db = walk(os.path.join(A, sub)), walk(os.path.join(B, sub))
    diff = [k for k in set(da) & set(db) if sha(da[k]) != sha(db[k])]
    print(sub, len(da), len(db), 'diff=', len(diff),
          'onlyA=', len(set(da) - set(db)), 'onlyB=', len(set(db) - set(da)))
```
